# Forest baseline acceptance — ML-028

Owned numeric and primitive CC0-1.0 material. Sources are byte-for-byte copies of the complete owned placeholder forest closure, including Clearing, catalogs, baseline profiles, tileset and expanded tree provenance. No RigLab bundle, borrowed art, combat implementation or new ability family is required. Export excludes the project/prefab documents and includes the five pinned public schemas.

The input schedules and final-byte witnesses bind the I4 checklist:

`tests/consumer/forest.mjs` imports only Node built-ins and the independent format reader. Its movement adapter is deliberately qualified to this static, rectangular-actor, fixed single-jump, neutral-material journey and the authored rectangular sensors. It does not reimplement arbitrary climb, dash, complex material, camera interpolation, navigation search or engine AI. Full ladder/rope/drop and patrol witnesses are separately replayed by the named existing reference systems; the consumer constructs their source intent. Hashes establish integrity, not publisher authenticity. Coherently rehashed trace, geometry and completion-action mutations must still fail semantic checks.

Integration repairs preserve source geometry and contracts: unrelated profile-bound flight volumes no longer disable ground navigation; the forest's rectangular zero-penalty `forbid` restrictions on jump/fall/drop test full-body X/Y sweeps and final chained replay. Links, matching mode transitions, nonrectangular/penalized/other-action overrides remain unsupported. A fall candidate that enters a connected ground support without ever becoming airborne is discarded as ground movement. A 512-tick default action budget for slow ground-only profiles accommodates the authored 360-WU slow ground-patrol leg. Bounded no-route results do not certify global unreachability.

`export.expected.json` pins the repeat-export manifest/ZIP digests. `construction.expected.json` pins the independent constructed-world digest/report. `index.json` hashes every other final corpus file. Main and focused recordings are fixtures, never map edits or saves. No release/deployment is part of this milestone.
