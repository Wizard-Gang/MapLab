# Integrated Test runtime — ML-020

Owned CC0-1.0 MapLab fixtures. Forest map/profile bytes are copied unchanged from the owned ML-019 climb fixtures. No RigLab or borrowed art is required. `index.json` pins every final file. Each `*.input.json` is the exact bounded recording accepted by the integrated Test panel; `*.expected.json` pins every shared-controller state/contact and trace hash, not just the endpoint.

The four forest scenarios prove walk/run/brake/jump/landing from the authored default start, bottom-to-top ladder exit, full-footprint west jump/airborne rope grab, and elevated one-way drop/rearm/landing. Initial seeds are explicit for isolated ladder/rope/drop reproduction; replay always runs against the current frozen map/profile. The reference full-footprint west takeoff at x468 grabs on input tick12 (the resulting state is tick13). The provisional edge-centered tick10 sketch remains distinct; the tiny ML-019 tick10 fixture and all its original bytes remain unchanged.

TestSession owns a recursively frozen source/profile snapshot and immutable runtime views; it imports only contracts and the same pure `createWorld`/`step` entry points used by replay/navigation witnesses. No source, history, derived navigation, gameplay, AI, combat or inventory mutation occurs. Reset returns to the snapshot's authored spawn; replay accepts an explicit initial state and absolute run-length input schedule and pauses at its end. Failed imports are atomic. Controller failures retain the failing frame, pause and display the exact status/reason. Playback is limited to3600 ticks per recording (60 seconds); reset starts a fresh recording. Tick units are integer su at60Hz; wall time only schedules ticks.

The generic rectangle and foot/contact witnesses render the snapshot; HUD exposes foot WU, integer velocity su/tick, support/traversal/plane IDs, state/facing and raw contacts including finite-body poses. No graph/route exists yet, so the panel explicitly reports unavailable navigation and cannot certify. Changing profile stops Test and requires an explicit new snapshot. Any authored model/history replacement stops and discards Test. Tab switch/unmount/window blur/hidden document pauses; input focus loss clears held keys. The stage owns arrows/Shift/Space/D; text fields keep normal editing.

`tests/consumer/test-runtime.mjs` runs a copied/stripped runtime in an independent Node process with final fixture bytes, no editor/library/React/render/DOM/dev-server dependencies, and checks every frame and recovered recording. Browser gates exercise the real panel and the same exact checkpoints in Chromium and WebKit.
