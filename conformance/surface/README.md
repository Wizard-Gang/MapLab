# Owned surface/climb fixtures (CC0-1.0)

Original numeric MapLab fixtures, adapted from the owned ML-017 contact and ML-019 climb packages. No borrowed artwork or engine assets. The index hashes every final source/profile/case/graph byte. Graph files pin exact deterministic intervals and full controller motion witnesses; revision1 is the fixture revision.

The integer-su lattice is exhaustive within the declared sample budget. A slope uses the actual full-footprint standing pose, not center-line shrink. The slope fixture admits x12–52WU; its standing foot at x40 is y74WU. The flat 256WU platform admits centers12–244WU for the24WU-wide body. The narrow passage cannot accommodate its48WU height. Material hazard bans remove support, and aToB permits only rightward walking. Ladder direction and per-profile climb abilities gate actual replay edges. The no-jump enemy retains ground walking; a no-jump climber independently retains ladder movement.

`maplab.surface-graph` is an internal rebuildable candidate graph, not the exported maplab.navigation certificate. Nodes are representative rest anchors within intervals. A walking edge terminates in the destination interval near its representative anchor; the exact terminal pose/velocity remains in its replay. It cannot be substituted for another edge's initial state. No search, airborne transition or chained-route certificate is supplied. A later search solver must replay compatible chained states.

`tests/consumer/surface.mjs` reads only final bytes in a separate process, imports no MapLab modules, checks hashes and semantic references/permissions, and independently checks the numeric flat, slope, clearance, material and direction cases. Unit tests separately replay every witness with the shared controller, check source immutability, controller source digest, cache invalidation, bounded work, cancellation and stale publication. Browser tests exercise the actual module-worker transport in both engines. Earlier forest recordings remain unchanged: input tick12 produces attached state tick13; the provisional tick10 example is distinct.

Three-piece reciprocal one-way welds A[0,100], B[100,104], C[104,256]WU test nonadjacent restrictions under the24WU body. A hazard ban on C caps all legal centers at92WU; bToA on C splits A at92WU and excludes rightward witnesses touching C while retaining leftward permission. Both cases have full replay goldens and independent final-byte arithmetic checks. Walk and climb tick caps report distinct diagnostics, discard every partial interval/node/edge and cannot warm the session LRU; sample exhaustion is tested separately.
