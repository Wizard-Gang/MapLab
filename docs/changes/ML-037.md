# [ML-037] [FEATURE] Add bounded swimming and flight turn-state witnesses

## Change

Add finite-body swimming, explicit entry/exit witnesses and flight velocity-state search.

## Reason

Profiles need water-bound routes and momentum-aware flight corners.

## Impact

Separate supported mode motor and bounded planner preserve authored geometry and existing controllers.

## Risk

Volume seams, blocked transitions, retained velocity and wrong-mode profiles may invalidate a route.

## Controls

Owned CC0 cases, exact integer replay, negative cases, independent consumer and browser coverage.

Pending pinned clean install, local non-test checks and exact-head CI. Local tests are prohibited.
