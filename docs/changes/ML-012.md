# [ML-012] [FEATURE] Add physical geometry handles and atomic topology edits

## Change

Append verified ML-011 delivery evidence, retire ML-011 and activate ML-012.
Preserve ML-013–044 byte-identically. Add foothold endpoints, body origins and
collider vertices in Platforms/Collision modes, plus explicit snap/connect,
disconnect, split/join and solid-edge ownership commands.

## Reason

Physical geometry needs persistent identity, exact edge ownership and atomic
reference repair as it is reshaped, independently of artwork.

## Impact

CSS-sized handles use the shared transform and grid/free world snapping. Preview
holds only a handle/point in the external per-document selection session. Release
builds one command; Escape, pointercancel, lost capture, blur and resize discard
preview. Secondary pointers cannot move the captured preview. Numeric inspector
fields provide keyboard editing, with complete source validation at commit.

Split retains the left foothold ID and allocates the right ID. Rect/polygon solid
edges subdivide while preserving the shape ID and remapping later edge indexes;
solid segments split into two stable shapes. Surface anchors, nested access/AI,
waypoints and endpoint links remap in the same command. Join retains the selected
ID only for adjacent collinear supports with identical physical properties and
compatible collider ownership. Welded seam handles update reciprocal neighbors
and owning collider vertices. Solid-edge assignment synchronizes collision flags
and exact endpoints. Ambiguous edge-dependent splits require explicit repair. Solid/one-way weld
compatibility is validated for source and ownership conversion as well as connect.

## Risk

Splitting a rect changes its representation to an equivalent polygon. Surface u
is serialized on its declared 1/65536 quantum after resolving original x. Invalid
supports, ownership, traversal access and cross-document references fail closed
with explicit diagnostics. Art stays on its independent canvas; physical handles
and overlays do not hide it. Full validation runs at command boundaries, never
per pointer event. No generated tile collision or physics simulation is added.

## Controls

Exact Node 26.10.0/npm 12.1.0, unchanged lockfile and Playwright 1.64.1. No new
dependency. One branch/PR with identical commit subjects. Clean install,
canonical/browser/security/policy gates, independent exact-head read-only review
and authenticated delivery verification precede SHA-guarded squash. Resulting
main CI and completed branch deletion follow it. No release or deployment.

## Validation

Owned CC0 physical edit fixtures pin flat/slope/one-way seams, topology,
reference and cancellation cases. Unit checks cover one-entry undo/redo,
full-source validation, stable IDs, ownership and negative edits. A separate
process with only consumer/schema copies reads final split and joined bytes and
rejects a dangling support. Chromium and WebKit exercise real pointer capture,
release, cancellation, focus, resizing, ownership, save and independent overlays.
Deep hierarchy/long anchor fixtures and their tracing policy remain intact.
Exact-head results are recorded externally in ML-012/ledger.json.
