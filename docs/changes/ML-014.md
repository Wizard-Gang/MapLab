# [ML-014] [FEATURE] Add deterministic terrain rules, variation and transform permissions

## Change

Append verified ML-013 delivery evidence, retire ML-013 and activate ML-014.
Preserve ML-015–044 byte-identically. Add terrain-intent painting that resolves
explicit tiles from the tileset's 8-neighbor rules with a pinned variation hash,
reseeding, and a transform tool that turns or mirrors painted cells only where
the tileset permits.

## Reason

Terrain needs deterministic, reproducible tile output from authored intent, so
consumers read explicit tiles and never need an autotile engine.

## Impact

Terrain intent is a packed, chunked store beside the cells; an `intent` delta
operation records it as compactly as paint. Painting terrain writes intent and
the resolved tiles of every painted cell and its eight neighbors in one paint
plus intent transaction, so one undo restores both. A literal tile edit on an
intent cell clears that cell's intent in the same transaction and re-resolves
its neighbors, so every intent cell always stores its resolved tile.

Rules version 1, pinned here: bit k of a cell's mask is set when the neighbor in
direction k (N, NE, E, SE, S, SW, W, NW; Y down) has the same terrain intent. A
rule applies when its terrain and mask equal the cell's exactly; the highest
priority wins, then the lowest rule ID by code unit. Without a rule the
terrain's fallback tile is used. Variation takes 64-bit FNV-1a over the ASCII
bytes `seed NUL layerId NUL column NUL row NUL ruleId` (decimal integers),
reduced modulo the rule's integer weight total and walked through cumulative
weights. Outputs carry no transform.

The transform tool rotates 90° clockwise or mirrors every painted cell in a
dragged rectangle, composed after the cell's existing transform, and refuses
the whole gesture when any result is not permitted. Library form now writes
terrain intent in row-then-column order.

## Risk

Terrain edits remain art only: a transaction holds paint and intent operations
(plus the seed setting when reseeding) and nothing else. Gestures keep the
65,536-cell limit, so resolution touches at most nine cells per painted cell;
reseeding over more intent cells is refused whole. Rules never infer collision.
No rule language beyond the tileset's exact masks is added. Erasing in terrain
mode clears both intent and tile; turning or literally painting an intent cell
makes it literal. A stored file with repeated or malformed intent cells is
refused at normalization, as repeated chunks already are. The `maplab.palette`
library document format (R1 F1 lists ML-013/014) still has no contract; no
reserved task scope names it, so it is recorded for the owner's decision.

## Validation

Owned CC0 terrain-rule fixtures pin neighbor edge and corner cases across chunk
boundaries, priority and ID tie-breaks, fallback tiles, transitions between two
terrains, hash vectors, weighted variation, same-seed repeated builds, an
illegal 90-degree turn and single-undo neighbor updates, with golden resolved
bytes from an independent reference. A seeded property keeps every intent cell
equal to its resolution across random terrain, literal, erase, turn and reseed
edits, replays exactly and undoes to the base. Model checks cover intent
normalization, library-form order and refused direct intent writes. Chromium
and WebKit exercise terrain painting, cancellation, neighbor updates, transform
refusal, literal overrides, reseeding and save. Same-size canvas layout shifts
and document scrolling during capture cancel the entire gesture before another
coordinate is consumed; this prevents a stationary pointer from painting a second
cell as asynchronous draft UI changes the page. Draft notifications reserve their geometry and the cursor readout has a fixed
height, so asynchronous status changes do not move the canvas. A separate browser
regression forces both layout motion and scrolling and checks zero history/source
mutation; the original literal-paint assertions remain unchanged.
ML-013's suites stay green.
Exact-head results are recorded externally in ML-014/ledger.json.
