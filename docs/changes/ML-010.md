# [ML-010] [FEATURE] Add Canvas viewport, transforms and independent overlays

## Change

Record ML-009's verified protected squash and main CI, retire it and promote
ML-010. Preserve ML-011–044 byte-for-byte. Add the viewport to the existing
library editor, using its normalized document and a small per-document external
session for camera, snap and overlay choices.

`src/render/transform.ts` is the shared world↔CSS transform. Its inverse, canvas
matrix, CSS handle lengths, cursor zoom, panning, fit, resize, signed floor
division and snapping share that contract. DPR changes backing dimensions only.
`src/render/scene.ts` builds backend-neutral primitives on model changes, with
source layer paint order, body-local physical geometry, foothold IDs/normals,
resolved anchors/routes and independent authored intent/zone passes.
`src/render/canvas.ts` draws stacked art and overlay canvases with culling,
coalesced dirty redraws and display-only grid decimation.
`src/editor/viewport.ts` owns transient state; `src/app/Viewport.tsx` provides
focus-scoped wheel/keyboard/pointer input and accessible controls.

## Reason

ML-010 establishes the shared coordinate and Canvas foundation for later tools.
A device pixel ratio, canvas resize or art visibility change must never change
physical coordinates, document history or library bytes. Browser tests exercise
the input contract in WebKit and Chromium using the existing approved runner.

## Impact

Open maps now show the world. Wheel pans; Ctrl/Command+wheel zooms at the pointer.
Space+drag, middle drag and the Pan tool use pointer capture. Escape, pointer
cancellation, lost capture and focus loss restore the pan's start. Arrow keys
pan only while the viewport has focus. Fit/zoom buttons work without a pointer.
Resize preserves the world center. Tabs keep independent camera/overlay sessions.

Every R1 C6 overlay toggles independently, including per-layer art. Physics focus
dims art to 30%; hiding art never disables physical geometry. Grid spacing and
origin are independent per axis on the 1/16 WU quantum. Free placement bypasses
the grid, and the cursor reports the final serialization-quantum candidate.

Navigation shows authored intent only; camera and environment passes outline
authored zones. Derived graphs, camera simulation, handles/selection, tile tools
and asset decoding retain their reserved owners. Existing asset references show
markers. The unchanged forest example supplies shape art. There is no WebGL,
new dependency, release or deployment.

## Risk

Risks include DPR drift, signed-coordinate mistakes, stuck capture/modifier state,
input leaking into text fields, and overlay controls changing authored content.
Invalid maps keep the recovery UI without rendering unsafe geometry. More than
4,096 visible repetitions of one background primitive are omitted with a visible
zoom-in notice, preventing tiny repeat periods from locking the editor.
One CSS transform, explicit cancellation and focus-scoped input address these.
Scene preparation occurs on model identity changes, never on pointer events.
The canvas is idle between dirty updates; art/overlay controls invalidate only
the affected canvas. Cached tile bitmaps, spatial picking and full performance
budgets belong to later scoped tasks rather than an ML-010 performance claim.

## Validation

Owned CC0 fixtures under `conformance/viewport/` pin numerical/session vectors
and the unchanged forest source by SHA-256. `tests/viewport.test.ts` interprets
them and checks independent expected CSS/buffer values, DPR 1/2/3, zoom
0.25–16, range extremes, negative cells/chunks, half-away quantum/grid snapping,
invalid grids, pan/cancel, resize, history immutability and separate source passes.

`tests/browser/viewport.spec.ts` runs actual wheel, modifier, pointer capture,
Escape/cancel/lost-capture, focus loss, field focus, resize, tab sessions and DPR
1/2/3 in WebKit and Chromium. Invalid-source recovery and bounded dense
background repetition are also exercised. Canvas pixel tests prove each overlay can draw
alone, toggles isolate art/overlay redraws, and Physics focus/art hiding preserve
physical output. Every test resets the shared scratch library. The existing
ML-009 suite remains part of the single serialized browser run.
The first independent exact-head review, at `7a5a7a9`, was blocked: a valid
entity-anchor chain longer than 64 links lost markers/endpoints (B1), and a valid
4,000-group layer hierarchy overflowed recursive scene preparation (B2).
Anchor resolution now uses an iterative cycle guard and memoized entity positions;
layer preparation uses an explicit preorder stack, and inherited art hiding uses
the same order without repeated ancestor scans. The pinned hierarchy recipe is
validated against the complete source graph before unit assertions; the browser
suite also opens it, pans and hides its root art group while overlays remain.
That large-source browser case disables Playwright DOM tracing only: WebKit
spent over seven seconds capturing its 4,000-layer DOM snapshot, exhausting the
assertion timeout. Every assertion remains; other cases retain failure traces.
The PR and external ledger retain exact-head results and review evidence.
