# [ML-011] [FEATURE] Add selection, atomic editing and remapped clipboard

## Change

Append verified ML-010 delivery evidence, retire ML-010 and activate ML-011.
Preserve ML-012–044 byte-identically. Add spatial Canvas picking, multi-selection,
move previews, duplicate/delete, hierarchy search, numeric inspector and a
versioned clipboard over the existing normalized document and history.

## Reason

Shared editor commands need atomic undo, persistent identity and explicit
reference repair before specialized geometry tools can build on them.

## Impact

Click selects in reverse painter order with geometric CSS tolerances, Shift
click toggles, Alt click cycles overlaps, and empty-space drag marquees. Pick
modes filter art, footholds, bodies, traversal and gameplay independently of art
visibility. Camera/parallax/repeated backgrounds remain hierarchy selectable.
Hierarchy buttons expose persistent IDs, names and parents, searchable by ID or
name, with keyboard navigation. Selection and camera persist separately per tab.

Drag shows transient translated selection outlines; release makes one compact
command. Escape, pointer cancellation, lost capture, resize and focus loss restore
the prior selection and discard preview. Body-attached/parented selection moves
once; layer and route movement expands descendants/waypoints. Unsupported free
movement, including movement beyond an anchor’s referenced surface and independently
selected solid footholds,
is refused with an explicit repair message. No source model is cloned per move.
Numeric fields commit on blur/Enter, Escape restores the field, and complete
schema/geometry/source-graph validation rejects invalid edits before history.

Copy/paste uses maplab.clipboard v1 JSON with bounded parsing, fresh top-level
and nested IDs and atomic internal-reference remapping. Pasted free positions
start 32 WU right/down, avoiding coincident physical support ownership; attached
records follow their pasted parent once. Resolving external IDs
survive. Missing targets block paste and can be explicitly repaired in the JSON
clipboard panel. Native copy/paste works outside fields; an in-app clipboard and
editable document panel remain available when browser permission is unavailable.
Delete lists dependents and offers cancel, retarget or an explicit preview and
confirmation of transitive cascade. Document/terrain references require retarget
rather than implicit removal. Full cross-document validation also blocks removal
of externally referenced objects. No dangling source is silently committed.

## Risk

Picking must follow painter order and the common transform. A bounded uniform
grid plus a broad-object bucket limits index expansion. CSS tolerance and handles
share transform.ts; DPR only affects Canvas backing buffers. Preview outlines
communicate movement without modifying the committed scene or document. Full
graph checks run at command boundaries, never on pointer movement. Source graph
inputs are cached outside React and refreshed from the library; final Save still
performs the authoritative fresh disk validation and conflict check.

## Controls

Exact Node 26.10.0/npm 12.1.0; existing Playwright 1.64.1 and lockfile; no new
dependency or lifecycle exception. One branch/PR and identical commit subjects.
Independent read-only exact-head review, canonical/browser/security checks and
live protected provider gates precede the head-guarded squash. Resulting main CI
and completed branch deletion follow it. No release or deployment.

## Validation

Owned CC0 selection fixtures pin expected numeric movement and cancellation,
mixed-drag, reference and clipboard cases. Unit tests exercise one-entry undo,
no-op and cancellation invariants, nested IDs, cyclic portal remapping, explicit
repair, mode filters, spatial geometry and CSS handle sizes. A separate reader process in an isolated folder containing
only the consumer and published schemas accepts final pasted bytes and rejects
a corrupted remapped reference, without editor imports. Chromium and WebKit
exercise actual pointer capture/cancel, focus loss, selection, inspector, focused
shortcuts, paste/save source bytes, deletion and independent tab sessions. The
ML-010 deep hierarchy and long-anchor tests remain unchanged. Exact-head results
and any repaired independent review findings are archived in the external ledger.
