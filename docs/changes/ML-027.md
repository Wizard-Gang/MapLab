# [ML-027] [FEATURE] Plan and replay constrained free-space flight patrols

## Change

Add a separate full-body hover/fly reference motor, obstacle-aware free-space lattice planner, worker protocol and Navigation flight panel. Resolve authored flight-volume unions by profile, reciprocal collision masks, native actor anchors, route order/waits and invalid-route fallback intent. Verified patrols replay every leg, including the return leg, through the motor.

## Reason

Ground support graphs cannot establish free-space flight reachability. ML-027 gives flying patrols their own bounded movement/search implementation and witness, with no borrowed ground edges or inferred mode-entry transition.

## Impact

Source schemas, ground controller and ground proofs remain unchanged. Flight uses existing fly/profile/mode-volume contracts and a separately identified reference subset, `maplab.reference-flight@1`. Proofs bind final motor/planner/collision implementation identities, static physical source, profile, settings, query and swept dependencies. Source edits/cancellation invalidate worker publication; queries never write source or history. Engine AI and fallback execution remain outside the proof.

## Risk

The conservative rectangular hover subset uses L1 speed/delta caps and rest-to-rest cardinal lattice turns, not a generalized kinodynamic optimizer. Matching non-rectangular volumes, non-hover/additional abilities, relevant overrides/links, moving colliders and launch/modifier intent report unsupported. Search failure is not universal unreachability. Existing carry risks remain: maplab.palette owner decision; loaded terrain-intent/resolved-output validation gaps; ML-041 approximately1.4 seconds/100k-cell validation and integer-su clearance scan cost; duplicate map-scoped local IDs.

## Controls

Full-body axis sweeps and exact rectangle-union containment cover each movement segment. Authored one-way supports conservatively become two-sided flight barriers; directional crossings and landing/mode transitions are not inferred. Native initial velocity is braked through the motor; unsafe braking is rejected. Ground states are not mode-entry witnesses. Closed schema/profile validation, coefficient/geometry/volume/node/expansion/replay/duration budgets, deterministic integer states, immutable captured inputs and revision/query/cache-key worker gates prevent partial or stale success. Unsupported route conditions/capabilities are explicit. No release or deployment.

## Validation

Twelve owned cases cover forest flight patrol, obstacle detour, narrow fit/oversized collider, thin wall, adjacent volume union/gap, outside body, profile-mismatched volume fallback, masks, initial braking and a complete closed obstacle patrol. A 48-tick 90-degree-turn/braking input witnesses retained momentum and turn caps. Unit checks include A*/Dijkstra duration agreement, ground-graph separation, capabilities, source closure, budgets, cancellation and stale replies. Chromium/WebKit exercise real worker proofs, read-only controls and source/history isolation. A standalone final-byte consumer independently replays motor equations and full swept geometry; coherent rehashing does not make forged traces pass.
