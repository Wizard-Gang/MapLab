# [ML-001] [CHORE] Establish governed planning foundation

## Change

Create private `Wizard-Gang/MapLab`, adopt the supplied architecture and ML-001–044
roadmap, add governance and desired policy, and build only the static React shell.

## Reason

Establish a reproducible independent foundation before implementing world contracts.

## Impact

`0.1.0` is unreleased. UI displays MapLab and planning-stage status only. No schema,
editor, physics/navigation, storage, engine integration, hosting or release exists.

## Risk

Initial main has no PR base and protections are not yet verified. Exact pins must
work together on the selected runtime. Documentation must distinguish plans from
implemented behavior.

## Controls

Empty-repository bootstrap only; private visibility; exact dependency/toolchain
pins; lifecycle script deny-all; least-privilege SHA-pinned foundation CI; meaningful
negative foundation fixtures. Live settings and additional jobs remain ML-002.

## Validation

Clean `npm ci` and `npm run check` passed locally on 16 October 2026
(America/New_York), using Node 26.10.0/npm 12.1.0. Installation added 46 packages
with lifecycle scripts denied. Foundation checks, TypeScript, both test files
(nine tests), Vite production build, and final-asset smoke passed. The tests include
seven malformed foundation copies rejected by the real CLI. An independent
read-only scope/governance review found no blocking issue. The initial attempt
using Node's bundled npm 11.19.1 was correctly rejected by engine-strict; all passing
results use npm 12.1.0. Exact final commands/results and push CI are recorded in the
external delivery report.

no commits or starting SHA. Authenticated `SouthernGentlemen` was an active
organization admin; full paginated organization inventory contained no MapLab and
repository lookup returned 404 before creation. Local clone confirmed unborn main.
This establishes the J3 exception rather than treating a lone 404 as absence.

Registry confirmed Node 26.10.0/npm 12.1.0 and React/React DOM 19.3.0,
TypeScript 7.0.2, Vite 8.3.1, Vitest 5.0.2 and declaration pins. Local Node was
obtained from the official Node distribution and matched its SHA-256 manifest.
The implementation session's delivery report records the final root commit hash
and its CI URL/outcome; those cannot be embedded in their own commit.
