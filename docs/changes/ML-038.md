# [ML-038] [FEATURE] Add bounded grapple attachment and swing witnesses

## Change

Activate ML-038 after verified ML-037 squash; implement named integer grapple attachment, reeling, swing and release witnesses.

## Reason

Grapple capability needs explicit physical anchors, line clearance and finite-body replay before a route can be reported reachable.

## Impact

Separate reference solver and bounded planner; source geometry and runtime rope state remain separate.

## Risk

Occluded attachment, rope constraint rounding, finite-body collision and stale results.

## Controls

Named solver, conservative supported geometry, exact integer state, bounded search and owned CC0 negative fixtures with independent final-byte consumption.
