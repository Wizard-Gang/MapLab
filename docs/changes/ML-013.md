# [ML-013] [FEATURE] Add sparse terrain painting tools and tileset palette

## Change

Append verified ML-012 delivery evidence, retire ML-012 and activate ML-013.
Preserve ML-014–044 byte-identically. Add Terrain mode with brush, rectangle,
line, bounded flood fill and erase over sparse signed 32×32 chunks, a tileset
palette that offers only permitted quarter turns and mirrors, Canvas 2D terrain
drawing and an affected-cell preview.

## Reason

Tile layers need authored terrain that edits in compact, atomic per-gesture
deltas without ever acquiring physical authority.

## Impact

Terrain mode routes primary-pointer drags to the active tile layer. Cells come
from the layer origin and cell size by floor division through the shared
transform, so negative space yields negative cells and chunks. The preview holds
only affected cell coordinates in an external per-document session; the overlay
draws them and the art canvas keeps committed cells. Release commits one paint
transaction; Escape, pointercancel, lost capture, focus loss, resize and a
document change discard the preview without touching source or history. A
gesture whose cells already hold the painted value records nothing.

Fill snapshots the committed store at pointer-down and walks a four-connected,
chunk-bounded frontier inside the map bounds. It runs in cancellable slices and
refuses a region over 65,536 cells rather than truncating it. Every terrain
gesture is capped at 65,536 cells. B/R/L/F/E select tools in Terrain mode only;
fields keep their keys. Terrain mode picks nothing. An art-only status states
that tile edits never change collision, footholds or navigation.

## Risk

A terrain transaction contains a single paint operation and nothing else, so
bodies, footholds, traversal and navigation records stay identical. Unknown
tiles, forbidden transforms and cells outside the ±131,072 WU range fail closed
at the command boundary with full source-graph validation. Tile art is drawn
from tileset shape visuals; asset-backed tiles show a neutral placeholder until
asset decoding lands. The library `maplab.palette` document format and
autotile/terrain-intent resolution remain future work.

## Controls

Exact Node 26.10.0/npm 12.1.0, unchanged lockfile and Playwright 1.64.1. No new
dependency. One branch/PR with identical commit subjects. Clean install,
canonical/browser/security/policy gates, independent exact-head read-only review
and authenticated delivery verification precede SHA-guarded squash. Resulting
main CI and completed branch deletion follow it. No release or deployment.

## Validation

Owned CC0 terrain fixtures pin negative chunk indices, bounded and cancelled
fills, the 10,000-cell history budget and terrain/art-only changes. Unit checks
cover seeded brush/replay properties against an independent reference grid,
one-entry undo/redo, no implicit collision differences and negative edits. The
real LibraryStore and loopback plugin refuse a forbidden cell at the command
boundary. A separate process with only consumer/schema copies reads final
negative-chunk bytes and rejects an unknown tile. Chromium and WebKit exercise
real pointer capture, release, cancellation, focus, resize, secondary pointers,
fill, palette transforms, read-only refusal, save and independent overlays.
Deep hierarchy/long anchor fixtures and their tracing policy remain intact.
Exact-head results are recorded externally in ML-013/ledger.json.
