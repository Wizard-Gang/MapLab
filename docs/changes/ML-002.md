# [ML-002] [SECURITY] Enforce delivery and repository gates

## Change

Activate ML-002 after verified bootstrap CI. Add separate exact-head CI jobs,
generic controlled-task/predecessor/event validation, negative regression fixtures,
online dependency vulnerability/signature gates, live policy apply/read-back and
strict premerge evidence verification. Close current use of the root exception.

## Reason

Every subsequent implementation needs authentic scoped PR delivery, successful
current-head checks and enforced private repository/tag/release protections.
The ML-001 checker intentionally accepted only bootstrap and could not do that.

## Impact

Only governance, tooling, CI and authorized settings change. The static shell,
exact runtime/dependency policy, MIT code and separate CC0 owned-fixture default
remain. Product contracts/physics/navigation remain future tasks. ML-001 historical
record and specification bytes are preserved.

## Risk

Live policy requires provider capabilities and admin access. Current organization
Free plan rejects private rulesets/protection with HTTP 403. Partial setting
application cannot be represented as full enforcement. Registry services can fail
or disclose newly vulnerable pinned dependencies and must block the online gate.

## Controls

One controlled branch/PR, no bypass or root reuse, explicit PR-head checkout,
immutable Action pins, read-only job credentials, denied dependency hooks,
all-severity audit and signature checks, closed metadata and predecessor continuity,
independent read-only review and exact-head provider evidence. Policy application
preserves privacy and unrelated rules. No release, publication or deployment.

## Validation

Clean `npm ci` and canonical `npm run check` passed on Node 26.10.0/npm 12.1.0:
56 tests across four files, typecheck, build and built-asset smoke. Online security
passed: zero known vulnerabilities, 46 verified registry signatures and 22 verified
attestations. Independent read-only review identified and prompted fixes for command stubs,
current-task-bound fixtures, inherited required checks and tag/deletion events.
Independent re-review found no remaining actionable code findings. Exact-head
provider CI remains pending at source commit creation; the scoped PR and external
ledger retain final results. Complete
live-policy read-back is mandatory and currently blocked by the provider plan;
this record makes no completed-delivery claim.
