# [ML-005] [FEATURE] Publish movement and controller contracts

## Change

Record ML-004's verified protected squash and green main CI, retire it to history,
and promote ML-005 while preserving ML-006–044 exactly. Publish the complete R1
movement schema, typed ability families, controller/collision contract,
machine-readable capability registry and deterministic complete-profile digest.

## Reason

Movement authoring must represent every D4/F family before phased solvers exist.
Unsupported configuration must stay explicit, and same-version coefficient edits
must invalidate navigation. Adopted R1's integer 60 Hz contract supersedes the
stale 120 Hz conformance summary.

## Impact

Pure consumers can validate player/ground/flyer profiles and every advanced family,
inspect support diagnostics and hash canonical profile bytes. Structural validity
is distinct from controller support/runtime implementation. Nothing in this task
certifies physics or navigation. Registered calls have a bounded scalar/typed-ref
envelope; ML-006 owns catalog field closure/reference resolution. No solver or UI.

## Risk

An accepted family could be mistaken for an implemented solver, or a partial hash
could retain stale caches. Frozen registry results expose those boundaries; all
source fields enter domain-normalized JCS/SHA-256. Resource, ratio, capsule,
duplicate and parameter checks reject malformed configuration. Owned positive
and negative fixtures, independent digest vectors and a separate final-byte
consumer process cover the profile boundary.

## Controls

One controlled branch, one PR and a head-guarded protected squash. Exact Node
26.10.0/npm 12.1.0, no dependency/lockfile changes, lifecycle denial and no network
schema or executable extension loading. Fresh canonical/security/provider checks,
independent exact-head review and authenticated policy/delivery read-back gate
delivery. No release or deployment.

## Validation

Node 26.10.0/npm 12.1.0: full `npm run check` passed foundation/queue contracts,
typecheck, 314 tests in eleven files, production build and final-asset smoke.
`npm run security` passed with zero vulnerabilities, 46 verified registry
signatures and 22 verified attestations. All 58 pinned movement cases pass:
24 valid configurations/digest vectors and 34 precise rejection cases. The six
R1 source/export profiles remain unchanged. No dependency or lockfile changed.

Independent review corrected an overly narrow collision-label whitelist to the
adopted explicit-key/symmetric-mask policy. No further actionable initial findings
remain. Fresh clean-install/exact-head canonical and security results, final
independent review, provider checks and authenticated delivery verification are
recorded with the PR before its guarded protected squash.
